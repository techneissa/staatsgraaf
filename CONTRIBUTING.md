# Contributions

Staatsgraaf does not accept pull requests, patches, or other contributions.

The site and the dataset are published for reading and reuse under the licences in `LICENSE` and `LICENSE-DATA`. The maintainer builds and updates them.

Issues are open for a wrong fact, a broken source, a removal request and an accessibility problem: https://github.com/techneissa/staatsgraaf/issues. Issues are public, so leave private details out. A security issue goes through `SECURITY.md`, not a public issue.
